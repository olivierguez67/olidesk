# Olidesk

Olidesk is a remote support application by Olisys, built for reliable and secure remote desktop access.

## About

Olidesk is a fork of RustDesk, rebranded and configured for Olisys customers.

- **App Name:** Olidesk
- **Company:** Olisys
- **Identifier:** com.olisys.olidesk
